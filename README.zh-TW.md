# listen-to-your-rag

[English](README.md) | **繁體中文**

**為領域文獻 RAG 設計的版面感知 PDF 擷取：方法、評測與結果紀錄**

這個 repo 記錄我們重建一套**受控環境農業（CEA）**研究文獻 RAG（檢索增強生成）系統「文字層」的**方法與結果**。文獻庫約 460 篇論文，主題包括植物工場、飽差（VPD）、光照、水耕與 AI agent。
這是一份**公開的實驗紀錄**：這裡不放程式碼，只公開方法、設計規格、評測流程與結果，並持續更新；規格詳細到可以用程式代理重建整個系統（見 [harness](harness/README.md)）。

## 為什麼要重建

第一版 RAG 索引（v1）逐頁擷取 PDF 文字，再每 500 字切一段。檢查後發現：

- **62%** 的段落沒有章節標籤（分不出摘要、方法、結果……）；
- 雙欄排版的論文，**左右兩欄的句子在同一行被拼在一起**；
- 頁首、頁尾、期刊資訊和表格殘片混在正文裡；
- 有 **78** 篇論文在檔案改名後，索引裡記錄的 PDF 路徑已經失效。

重建後的流程（v2）讓 **RAG 索引**和**英文朗讀工具**共用同一個擷取模組：人耳聽到的內容，就是檢索系統索引的內容。練聽力的同時，也等於在**稽核 RAG 語料的品質**。

## 初步結果

**評測 1：已知答案查詢**（每題只有 1 篇正確論文）。v3 是學習式比較組：用 Docling 擷取文字，之後的章節判斷、切段與向量模型都和 v2 相同，因此兩者只差在擷取工具。
報告：[v1 對 v2（2026-10-21）](docs/results/eval1-known-item-2026-10-21.md)・[v1、v2、v3 比較（2026-10-24）](docs/results/eval1-known-item-v3-docling-2026-10-24.md)・[指標說明](docs/results/metrics-guide.md)

**表 1.** 98 題（語料修正後剔除 2 題，見報告）。

| 指標 | 衡量什麼 | v1 | v2 | v3（Docling） |
|---|---|---|---|---|
| Hit@5 | 正確論文是否在前 5 名 | 0.949 | 0.980 | 0.980 |
| Hit@10 | 正確論文是否在前 10 名 | 0.969 | 1.000 | 0.990 |
| MRR@10 | 正確論文排得多前面（第 1 名 1 分、第 2 名 ½、第 3 名 ⅓……） | 0.849 | 0.893 | 0.897 |
| F1@5 | 前 5 名的精確率與召回率平衡（每題只有 1 篇正確時最高 0.333） | 0.316 | 0.327 | 0.327 |

- **v2 與 v3 打平**：v3 − v2 的差異都在 0.01 以內，皆不顯著。
- 兩者數值上都高於 v1，但**未達統計顯著**（MRR@10 +0.04～+0.05，95% 信賴區間皆包含 0）。
- **天花板效應**：98% 的題目都把正確論文排進前 5 名，本評測難以區分各版；主題查詢評測（[#4](https://github.com/kylecat/listen-to-your-rag/issues/4)）尚未進行。
- 2026-10-27 起以 v2 作為線上索引：檢索效果與 v3 相同，運算成本低很多（只用 CPU、數分鐘，對比 GPU 每頁約 0.4 秒）。

## 範圍與限制

- 本方法是**規則式**的版面處理。已發表的比較研究顯示，規則式解析工具在科學論文上普遍不如學習式工具（例如 Nougat、Docling、GROBID）。在本語料上，Docling 比較組的檢索效果並未較好（#5）；GROBID 與 Nougat 尚未測試。
- 各版都還沒有把表格與圖納入索引。
- **不散布**受版權保護的論文、擷取出來的文字，以及由這些內容產生的模型輸出。
- 結果來自單一領域的文獻庫，不一定能推廣到其他領域。

## 公開原則

- **引用經過查證**：每條文獻都對照原始出處；二手或未查證的來源會另外標註。
- **數字標明版本、誠實呈現**：結果註明日期、流程版本，以及是否為暫定數字；未經評測，不把差異說成改善。
- **寫出限制**：明確寫出範圍、失敗案例，以及本方法建立在既有研究上的事實。
- **AI 使用揭露**：揭露 AI 模型、版本與角色，並隨時更新；AI 產生的翻譯、描述與判斷一律標示。
- **不公開私人或有版權的內容**：不公開系統細節、帳密或受版權保護的論文內容。

## 作者與 AI 使用揭露

- **研究方向、決策與審閱**：[@kylecat](https://github.com/kylecat)
- **AI 助理**：**Iris**，以 Anthropic **Claude Opus 5.5**（`claude-opus-5-5`）為基礎的維運／研究助理，透過 Claude Code 在實驗室的 Jetson 主機上執行。

AI 負責的工作：
- 設計並實作擷取與切塊流程，執行索引重建與比較；
- 搜尋並查證相關文獻；
- 撰寫本 repo 的文件與圖；
- 撰寫日文論文的英文摘要（在索引中標示為翻譯）；
- 在評測中擔任 LLM 相關性判斷者，並以人工抽評計算一致性（Cohen's κ）檢核。

範圍、資料處理、公開與授權等決策，皆由人類作者決定。
