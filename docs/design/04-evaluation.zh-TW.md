# 04 · 評測設計（Evaluation design）
[English](04-evaluation.md) | **繁體中文**

> 狀態：**已規劃，尚未執行**（[#3](https://github.com/kylecat/listen-to-your-rag/issues/3)、[#4](https://github.com/kylecat/listen-to-your-rag/issues/4)）。結果發布時會註明日期與處理流程版本。

## 評估單位

以論文為單位，而非段落（切塊）：兩套索引切分文字的方式不同，因此計分前先把檢索到的 top-k 段落對應回論文並去除重複。

## 評測 1 — 已知答案查詢

| 項目 | 設計 |
|---|---|
| 樣本 | 兩套索引都收錄的 100 篇論文，固定亂數種子；排除重複論文與非英文論文 |
| 問題 | 由 LLM 閱讀**原始 PDF 文字**（不是任一索引的段落），寫出一題只有該篇論文能回答的英文問題；不得照抄原句，不得含標題字串 |
| 標準答案 | 該篇論文（以及任何已知的重複版本） |
| 指標 | Hit@5、Hit@10、MRR@10、F1@5（只有一個相關項目時，F1@5 只是 Hit@5 的轉換；列出但不強調） |

## 評測 2 — 主題查詢合併盲評

| 項目 | 設計 |
|---|---|
| 查詢 | 30 個領域主題（VPD、光譜、養液 EC、葉燒、CO₂ 施肥、植物工廠能耗、熱影像、蒸散／氣孔、農業中的 LLM agent…），經人類作者確認 |
| 候選池 | 各索引 top-10 論文的聯集（TREC 式候選池） |
| 判定 | 0 / 1 / 2 相關性判斷，**隱藏來源索引**，順序打亂；由 LLM 判定全部配對；人類作者判定其中 5–10 個查詢的子集 |
| 一致性 | 在子集上計算 LLM 與人類的 Cohen's κ；若 κ 偏低則擴大人工判定範圍（cf. Thomas et al., SIGIR 2024） |
| 指標 | P@10、R@10（相對於候選池）、F1@10、nDCG@10 |

## 統計

逐查詢配對比較：Wilcoxon 符號等級檢定與 bootstrap 95% CI（對查詢重抽 10,000 次）。只有 30 個主題查詢，應優先報告方向與 CI，避免過度解讀 p 值。

## 比較組

v1（原版）、v2（本處理流程），以及一個以學習為基礎的擷取器（GROBID 或 Docling），三者使用相同的切塊方式與向量模型（[#5](https://github.com/kylecat/listen-to-your-rag/issues/5)）。

## 效度威脅

- 出題者可能偏好容易找到的內容 → 固定抽樣、要求改寫用詞。
- LLM 評審可能偏寬鬆 → 人工子集與 κ。
- 候選池的召回率是相對於各系統找到的結果，並非整個語料庫的真實召回率。
- 只有單一領域語料庫。
